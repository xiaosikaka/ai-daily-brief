Meta 发布 Llama 3.2 系列模型，包含 70B、400B 及首个推理优化版本
📅 发布于 2026-04-07
核心内容： Meta AI 正式推出 Llama 3.2 系列，包含三个新模型：Llama 3.2 70B、Llama 3.2 400B 以及专为推理任务优化的 Llama 3.2 70B-Instruct。400B 版本在多项基准测试中表现优异，接近顶级闭源模型。同时，Meta 宣布与主要云服务商合作，提供托管 API 服务，并开源了 70B 和 400B 的预训练及指令微调模型权重。
价值： 这是 Meta 在开源大模型领域的又一次重大推进，400B 参数模型的开源将极大推动社区研究和应用开发，而推理优化版本和商业 API 的推出则显示了其加速技术落地的决心。

Anthropic 推出 Claude 3.5 Sonnet 的“长上下文工作记忆”实验性功能
📅 发布于 2026-04-06
核心内容： Anthropic 为 Claude 3.5 Sonnet 模型推出了一项名为“工作记忆”的实验性功能。该功能允许模型在对话中记住并持续引用高达 100 万个 token 的上下文信息，有效延长了其“记忆”时长，使其能在超长文档分析、复杂多轮任务规划等场景中表现更稳定、连贯。功能目前通过 API 向部分用户开放测试。
价值： 这是解决大模型“上下文遗忘”问题的实质性进展，通过技术手段显著扩展了模型的实际工作记忆容量，对处理长文档、代码库和复杂对话有重要价值。

Google DeepMind 发布 AlphaFold 3 Server，免费提供生物分子结构预测
📅 发布于 2026-04-07
核心内容： Google DeepMind 和 Isomorphic Labs 联合推出了 AlphaFold 3 Server，这是一个免费的研究工具。科学家只需输入分子描述，即可预测蛋白质、DNA、RNA 以及配体、离子和化学修饰物之间的相互作用结构。该服务旨在为非计算生物学背景的研究人员降低使用门槛，加速生命科学发现。
价值： 将顶级的 AlphaFold 3 模型通过免费服务器开放，极大降低了结构生物学研究的门槛，有望在药物发现、基础生物学研究等领域引发新一轮创新浪潮。
