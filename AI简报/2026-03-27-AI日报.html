Meta 发布 Llama 3.2 系列模型，包含 1B、3B、7B 和 70B 参数版本
📅 发布于 2026-03-27
核心内容： Meta AI 正式推出 Llama 3.2 系列开源模型，包含 1B、3B、7B 和 70B 四种参数规模。新模型在推理、代码生成和多语言能力上均有显著提升，特别是 1B 和 3B 版本专为移动和边缘设备优化，实现了高性能与低功耗的平衡。所有模型均遵循 Llama 3.1 的宽松许可协议，可供研究和商业使用。
价值： 这是 Meta 开源模型路线图的重要一步，提供了从移动端到云端全栈的模型选择，极大降低了开发者在不同场景下的部署门槛，可能加速 AI 在终端设备的普及。

Google DeepMind 推出 AlphaFold 3 Server，免费提供非商业蛋白质结构预测
📅 发布于 2026-03-27
核心内容： Google DeepMind 和 Isomorphic Labs 联合推出了 AlphaFold 3 Server，这是一个免费的研究工具。科学家只需输入分子序列，即可预测蛋白质、DNA、RNA 及配体等生物分子的结构和相互作用，预测速度比原版 AlphaFold 3 更快。该服务旨在加速非商业性科学研究，如药物发现和疾病机理探索。
价值： 将顶级的 AlphaFold 3 能力通过免费服务器开放，极大降低了生命科学领域的研究门槛，有望在基础科研和早期药物研发中引发新一轮创新浪潮。

Anthropic 发布 Claude 3.5 Sonnet 的“长上下文”版本，支持 200K 上下文窗口
📅 发布于 2026-03-26
核心内容： Anthropic 为 Claude 3.5 Sonnet 模型推出了“长上下文”（Long Context）版本，将上下文窗口从标准的 128K 令牌扩展至 200K 令牌。该版本在长文档理解、代码库分析和复杂多步骤任务中表现更优，现已通过 Claude API 和 Claude.ai 平台向所有用户开放。
价值： 直接回应了市场对超长上下文处理能力的迫切需求，增强了 Claude 在处理大型项目、法律文档和长篇研究时的实用性，巩固了其在企业级应用中的竞争力。
